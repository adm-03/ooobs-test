# Orders sync

Забирает заявки с `https://test.ooobs.ru/api/orders`, нормализует телефоны к `+7XXXXXXXXXX`,
дедуплицирует по телефону (max `amount`, при равенстве — позже `created_at`).

- `GET /` и `GET /api/clients` — результат (кэш 30 с, при сбое источника отдаётся последний снимок)
- `POST /api/sync` — принудительная синхронизация; результат заменяется целиком, поэтому повтор идемпотентен
- `GET /health`

Запуск: `uv run uvicorn app.main:app`. Тесты: `uv run pytest`. Деплой: Dockerfile / `render.yaml` (Render, Railway, Fly).

Vercel: репозиторий деплоится без настроек (FastAPI находится по `app/main.py`).

## Подход, стек, секреты

Стек: Python 3.13, FastAPI, httpx, uv; деплой на Vercel (есть Dockerfile для любого контейнерного хостинга). Логика (`app/domain.py`) — чистые функции без I/O, HTTP-слой (`app/main.py`) тонкий; состояния и БД нет — ответ целиком пересчитывается из источника, поэтому синхронизация идемпотентна.

Секретов в проекте нет: источник заявок публичный и без авторизации, токенов и ключей код не использует. Настройки (`ORDERS_URL`, `CACHE_TTL_SECONDS`) — переменные окружения с безопасными значениями по умолчанию. Если секреты появятся, они живут только в Environment Variables хостинга (Vercel/Render), а не в git; `.env` в `.gitignore`.
